# GoGreen · site

Landing page e política de privacidade do app GoGreen, publicadas em https://gogreen.app.br pelo GitHub Pages.

- `index.html`: landing
- `privacidade/index.html`: política de privacidade (link usado na Google Play)
- `CNAME`: domínio próprio

Para mudar o e-mail de contato ou ligar o botão da Google Play, edite `CONTATO_EMAIL` e `LINK_PLAY` no script do fim de cada página.
